# FuckCaptcha brand assets

`logo-mark` is the project’s single mark: a violet tile with code brackets around a soft-green check. Each banner and wordmark has an editable SVG source and a PNG export. SVGs embed subset Inter and JetBrains Mono fonts, so they render the same everywhere.

| Asset | SVG size | PNG export | Use |
| --- | --- | --- | --- |
| `logo-mark.svg` / `.png` | 512×512 | 512×512 | Primary mark for site navigation, app icons and avatars. |
| `logo-horizontal-dark.svg` / `.png` | 1040×280 | 2080×560 (@2x) | Wordmark on dark backgrounds. |
| `logo-horizontal-light.svg` / `.png` | 1040×280 | 2080×560 (@2x) | Wordmark on light backgrounds. |
| `readme-banner.svg` / `.png` | 1280×320 | 2560×640 (@2x) | Dark README banner. |
| `readme-banner-light.svg` / `.png` | 1280×320 | 2560×640 (@2x) | Light README banner. |
| `social-preview.svg` / `.png` | 1280×640 | 1280×640 | Dark social preview. |
| `social-preview-light.svg` / `.png` | 1280×640 | 1280×640 | Light Open Graph and GitHub social preview. |

Mark gradient: `#a395e6` → `#6150a8`, check `#b7f2d2`.

## Typography

- **Inter** ExtraBold for the wordmark and headlines, Regular/Medium for body copy.
- **JetBrains Mono** SemiBold for eyebrows, chips and labels.

## GitHub social preview

Upload `social-preview-light.png` in **Settings → General → Social preview** for the light version used by Open Graph metadata.
