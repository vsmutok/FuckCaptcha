# FuckCaptcha brand assets

`logo-mark` is the project’s single mark. Each banner and wordmark has an editable SVG source and a PNG export.

| Asset | Size | Use |
| --- | --- | --- |
| `logo-mark.svg` / `.png` | 512×512 | Primary mark for site navigation, app icons and avatars. |
| `logo-horizontal-dark.svg` / `.png` | 1040×280 | Wordmark on dark backgrounds. |
| `logo-horizontal-light.svg` / `.png` | 1040×280 | Wordmark on light backgrounds. |
| `readme-banner.svg` / `.png` | 1280×320 | Dark README banner. |
| `readme-banner-light.svg` / `.png` | 1280×320 | Light README banner. |
| `social-preview.svg` / `.png` | 1280×640 | Dark social preview. |
| `social-preview-light.svg` / `.png` | 1280×640 | Light Open Graph and GitHub social preview. |

Upload `social-preview-light.png` in **Settings → General → Social preview** for the light version used by Open Graph metadata.
